# 架构改造实施记录

## 本次范围

按用户确认，暂不建设 HTTPS 入口、统一后端、数据库、跨设备同步和账号恢复。现有账号仍是浏览器本机加密账号，不是服务器账号。

## 已落地

- 学堂、起卦、报告拆成独立功能模块，按需载入；样式按基础、学堂和响应式拆文件。共享十神、十二长生与解释计算移入 core，移除重复实现。
- URL 保存页面和古籍书卷位置；支持刷新、后退、古籍段落链接。私有报告链接必须先解锁对应本机账号，不能凭 ID 读取其他账号。
- 显式分析基准日期控制报告中的年份。真实年度节气确定 12 个流月，流日覆盖整个交节区间，并标示北京时间和首尾边界。
- 未知时辰不把正午占位时柱计入五行；隐藏不能确定的旺衰、喜用、格局、亲属和岁运详批。日柱仍是核历暂定值，换日附近须补资料核实。
- 档案保存完整报告快照；打开不自动重算，主动重算新增历史版本。以档案 ID 区分资料，不再用同姓名、日期、时间合并不同命盘。
- 四家规则分别使用月令透藏、季节调节、根气流通和柱位十神等事实，附规则编号、输入依赖和反证条件。部分结论可跳到具体本地古籍段落。
- 六部古籍 180 篇/卷、9,200 个正文块建立内容哈希版本和段落 ID；保留旧版本引用。全文索引支持繁简归一化检索，结果可直达原文。
- 公共章节迁移到独立 Cache Storage；支持整书下载、取消和删除，清理旧章节 localStorage 缓存而不动私有档案。HTTPS/localhost 安全上下文下可离线使用。
- 现代译文独立记录作者、版本和审核状态。本次提供 4 段待校订示例，不把导读或旧注冒充全书现代译文。
- 内容生产增加原始响应归档与发布前检查：缺篇、空段、重复章节 ID、残留 Wiki 标记、正文异常缩短会阻止分篇发布。版本正文先写入，目录采用原子替换。
- 本机保存成功后再提交内存状态；空间不足或跨标签页版本冲突明确提示，不悄悄覆盖。公开账号资料使用白名单，导出不携带密码验证材料。
- 古籍 JSON 缺失返回 404；目录重新验证，哈希正文长期缓存；启用 gzip。Service Worker 不再把数据/API 请求回退成 HTML，也不清理其他应用缓存。
- 增加 8002 服务器发布脚本，固定现有 Nginx 镜像摘要，串行发布，保留旧制品、配置和旧资源，失败自动回滚。版本可查询 `/release.json`。
- 新增 GitHub 手动发布工作流；运行前需配置 production 环境的 `DEPLOY_SSH_KEY` 和经过核对的 `DEPLOY_KNOWN_HOSTS`。本次未把本机私钥上传到 GitHub。
- 修复依赖审计发现的 nanoid 告警，锁定到修复版本 3.3.18。

## 验证

- 类型检查、23 项回归测试、生产构建通过。
- Playwright 使用实际 Chrome 验证：游客排盘，年/月/日切换，12 流月和完整流日，未知时辰边界，注册及加密档案，历史重算版本，重新登录恢复报告。
- 验证古籍刷新、后退、整书离线阅读，以及 390px 手机视口的阅读和学习栏目切换；无页面级横向溢出或 JavaScript 页面异常。
- 入口脚本从评估基线 406.50 KB 降至约 253.29 KB，构建估算 gzip 从 127.90 KB 降至约 80.47 KB。此为制品体积，不是首屏耗时实测。
- 繁简转换全字典仍有约 1.18 MB 独立分包，仅相关功能使用时载入；没有为消除构建提示牺牲转换覆盖范围。

本地复验：`npm run check`。浏览器回归：配置 `PLAYWRIGHT_MODULE`、可选 `CHROME_PATH` 和 `TEST_URL` 后运行 `node scripts/browser-check.mjs`。

服务器发布：`bash scripts/deploy-server.sh`。只操作 `/opt/shanyi-paipan` 和 8002，不操作 8000/8001 的其他站点。

## 尚不能宣称完成的内容

工程规则通过不等于命理预测准确；尚无外部专家标注集或预测准确率回测。四家输出是可追溯规则初筛，不是四位专家的一致结论。

古籍全文校勘、复杂表格语义复核和逐段现代译文仍需要持续编辑审核，自动检查只能发现结构异常，不能证明字句准确。

远程反馈接收、集中错误看板和自动告警需要配置真实接收服务；在后端暂缓期间，已有本机记录和发布健康检查不能冒充运营方已收到反馈。

公网 HTTP 下 Web Crypto、Service Worker 和 Cache Storage 仍受浏览器安全上下文限制。暂缓证书不代表这个限制已经消失，不应把当前公网入口宣传为正式可用的跨设备账号服务。
